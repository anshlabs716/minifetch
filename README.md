# minifetch
like neofetch but mini good for termux
#how to run 
```
#clone the repo
git clone https://github.com/anshlabs716/minifetch.git

#now run the script
chmod +x minifetch.sh
bash minifetch.sh
#or if that doesnt work
./minifetch.sh

#or if want to run it natively like neofetch
sudo mv minifetch.sh /usr/local/bin/minifetch

#or for termux
mv minifetch.sh $PREFIX/bin/minifetch
```
